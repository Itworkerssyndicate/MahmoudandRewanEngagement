أداة تهيئة قاعدة البيانات

حل مشكلة الصلاحيات وتهيئة قاعدة البيانات

Mahmoud & Rewan

⚠️ المشكلة: قاعدة البيانات ترفض الكتابة

السبب: إعدادات الأمان (Rules) في Firebase تمنع الكتابة حالياً.

الحل: اتبع الخطوات أدناه لتحديث قواعد الأمان أولاً، ثم اضغط زر التهيئة.

📋 الخطوة 1: نسخ قواعد الأمان

انسخ الكود التالي واذهب إلى Firebase Console لتحديث القواعد:

📋 نسخ // قواعد أمان Firebase Realtime Database // لدعوة زفاف Mahmoud & Rewan { "rules": { "settings": { ".read": true, ".write": true }, "comments": { ".read": true, ".write": true, "$commentId": { ".validate": "newData.hasChildren(['name', 'side', 'status', 'message', 'timestamp'])", "name": { ".validate": "newData.isString() && newData.val().length <= 100" }, "side": { ".validate": "newData.isString() && (newData.val() === 'groom' || newData.val() === 'bride')" }, "status": { ".validate": "newData.isString() && (newData.val() === 'attending' || newData.val() === 'maybe' || newData.val() === 'declined')" }, "message": { ".validate": "newData.isString() && newData.val().length <= 500" }, "timestamp": { ".validate": "newData.isNumber()" } } } } }

📝 الخطوة 2: تطبيق القواعد في Firebase Console

1 اذهب إلى Firebase Console - Rules
2 احذف القواعد القديمة الموجودة
3 الصق الكود المنسوخ أعلاه 👆
4 اضغط زر "Publish" أو "نشر"
5 ارجع لهذه الصفحة واضغط "اختبار الاتصال" ثم "بدء التهيئة"

💡 نصيحة: بعد نجاح التهيئة، يمكنك إعادة القواعد إلى الوضع الآمن:
".read": true, ".write": "auth != null"
